## Feature Ideas

- **Garbage Mode**: Players can select which opponent they attack using taunt buttons to cycle through targets
- **Multiple Lives**: Players start with multiple lives instead of single elimination—each death costs a life
- **Configurable Match Format**: Pre-choose match count (first to 2, first to 5, first to 10) or set custom win requirements per player (handicaps)
- **Point Betting**: Players can bet points on match outcomes across all game modes
