Replay Files

Opening a replay by drag and drop

Drop a replay file onto the running game window while in an offline menu.
Files are loaded as JSON replays regardless of their filename extension.
The replay details appear first; press confirm to watch it using the usual replay controls.
The file is read in place, not copied into the replay library or modified.
Dropping another replay during playback stops the current replay and shows the new replay's details.
Invalid or unreadable files play the cancel sound and log a warning without replacing the current screen or replay.
Dropping from another offline menu returns to the existing replay browser, or opens it above the main menu.
Malformed display metadata and invalid controller or touch inputs are rejected before stopping an existing replay.
The replay browser uses the same file loading and validation as drag and drop.
Validation checks replay data directly without starting a match, and accepts legacy touch idle frames.
Replays from incompatible engine versions show the usual version warning and cannot be played.
Wait for startup and scene transitions to finish, and leave any battle room or online session before dropping a replay.
No operating-system file association is needed. This does not add double-click-to-open support.

"in_buf" and "I" represent P1's and P2's inputs, respectively. Every character represents a frame.

Inputs are mapped to binary values.
0 - (do nothing)
1 - Right
2 - Left
4 - Down
8 - Up
16 - Swap
32 - Raise Stack

There are 64 legal case-sensitive characters that can be put in a Replay, which are:

ABCDEFGHIJKLMNOPQRSTUVWXYZabcdefghijklmnopqrstuvwxyz1234567890+/

Using math, you can figure out what inputs go to each character by adding them together. These characters follow an index order, so consider them 0-63. 

For example, let's say that a player is inputting both down and right at the same time. Right is equal to 1, and Down is equal to 4. Therefore, we would add them both together (1 + 4 = 5) to reach the letter "F". (Remember that since we are dealing with indexes, we start counting at 0).

Common actions:

A = Do nothing
B = Move Right
C = Move Left
E = Move Down
I = Move Up
Q = Swap
g = Raise Stack

"P" and "O" represent P1's and P2's stacks, respectively.
